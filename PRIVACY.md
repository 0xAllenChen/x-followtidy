# Privacy Policy for X FollowTidy

Last updated: July 30, 2026

X FollowTidy is designed to work locally in the user's browser.

## Data handling

- X FollowTidy processes information visible on the user's X Following page, including account names, handles, profile image URLs, follower counts, follow-back status, and cleanup results.
- Cleanup settings, progress, scanned-account records, and cleanup history are stored only in Chrome local storage on the user's device.
- The extension does not operate a backend service.
- The extension does not transmit this information to the developer or an application server.
- The extension does not collect passwords, authentication tokens, payment information, analytics, or telemetry.
- The extension does not sell or share user data.

## Network access

X FollowTidy interacts with pages on `x.com` to read visible Following-list information and perform user-requested unfollow actions. The optional donation link opens GitHub Sponsors only after the user clicks it.

## Data retention and removal

Locally stored data remains on the user's device until the user clears the extension's storage or uninstalls X FollowTidy. The developer cannot access or recover this local data.

## Changes to this policy

If this policy changes, the updated version and revision date will be published at this URL.
