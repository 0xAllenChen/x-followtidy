# Privacy

X FollowTidy is designed to work locally in the user's browser.

## Data handling

- Account handles, scan results, settings, and cleanup history are stored only in Chrome local storage.
- The extension does not operate a backend service.
- The extension does not collect passwords, authentication tokens, payment information, analytics, or telemetry.
- The extension does not sell or share user data.

## Network access

X FollowTidy interacts with pages on `x.com` to read visible Following-list information and perform user-requested unfollow actions. The optional donation link opens GitHub Sponsors only after the user clicks it.

## Removing local data

Users can remove locally stored extension data by uninstalling X FollowTidy or clearing the extension's storage from Chrome.
